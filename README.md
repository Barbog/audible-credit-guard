# ChromePlugins

A collection of Chrome extensions.

| Extension | What it does | Status |
|---|---|---|
| [Credit Guard for Audible](audible-credit-guard/) | Warns you before Audible credits overflow your plan's cap and are lost | Chrome Web Store submission prepared; see `audible-credit-guard/store/SUBMISSION.md` |

Each extension lives in its own folder with `src/` (the shippable extension),
`test/`, `tools/` and `store/` (listing copy and assets).
